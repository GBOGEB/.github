# Security Policy

This is the default security policy for GBOGEB repositories that don't publish their own.

## Reporting a vulnerability

**Don't report security problems in public issues, discussions or pull requests.**

1. Open the repository's **Security** tab and choose **Report a vulnerability**. This sends a private report that only the maintainers can see.
2. If that button isn't shown, open a public issue titled `Security contact request` **with no details in it**, and the maintainer will set up a private channel with you.

Please include:

- what is affected (files, workflows, generated artifacts, versions or commit SHA);
- steps to reproduce or inspect the problem;
- the likely impact and any mitigation you know of.

## What happens next

The maintainer acknowledges the report, classifies its severity, fixes it on a private branch or advisory where needed, and credits you in the advisory unless you ask not to be named. Exploit details stay private until a fix has shipped.

## Supported versions

Only the default branch of each repository is supported. Fixes are not backported.
