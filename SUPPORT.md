# Getting help

- **Read first:** the repository's `README.md` and any `docs/` folder.
- **Questions:** open an issue with the **Question** form.
- **Bugs and feature ideas:** use the **Bug report** or **Feature request** issue form.
- **Security problems:** never in a public issue. Follow [SECURITY.md](SECURITY.md).

These repositories are maintained by one person alongside other work, so replies can take a few days. There is no paid or guaranteed support.
